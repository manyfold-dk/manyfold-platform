# Diagrams

The SVG pairs here (`*-light.svg`, `*-dark.svg`) are the illustrations of the Manyfold
organisation profile, copied so the repository's landing page is self-contained; the README
picks the pair with `<picture>` and `prefers-color-scheme`. One label was changed in the copy:
the delivery row of the platform diagram names Argo CD and GitHub Actions only, because the
Tekton pipelines were retired from this repository ([ADR-0006, amendment](../../adr/0006-cicd-tooling-selection.md)).
`manyfold-mark.svg` is the organisation's mark.
